# moneymuon

A very rudimentary CLI finance bookkeeper.
This is missing a lot of features planned for future releases. Please don't use this!

## Notes for usage if you really really really need this for some reason:
For now, I haven't fixed (and will not be fixing) the issue with running this either from startup or manually. To fix this yourself, I found that routing the execution through command prompt and your local Python executable works. In the future if this problem is solved somehow I can guarantee it will have been an accident.
